#### 1. PDF Safety & In-Place Routing
* **Confirmed by reading:** A PDF cannot be overwritten by a non-PDF, nor can a picture be overwritten by a PDF.
* **Trace (PDF in-place):** In [`JobQueue.swift:138`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/JobQueue.swift#L138), a PDF starting with `%PDF` fails `isIsobmff` (`ftyp`). In `Preset.plain(.fast)` or `Preset.plain(.quality)`, `preset.writesInPlace` is `true`. [`Engine.optimize`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/Engine.swift#L71) calls `squint_optimize_as(..., SQUINT_FORMAT_JPEG)`. In [`core/src/lib.rs:834`](file:///Users/bemeadows/Projects/.lanes/squint-sign/core/src/lib.rs#L834), `pdf::is_pdf` matches; because format is `JPEG`, it executes `pdf::rewrite` and returns `Optimized { converted_from: None }`. In [`Engine.swift:85`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/Engine.swift#L85), `outputExtension` reads `%PDF` magic and returns `"pdf"`. `preset.destination(for: url, outputExtension: "pdf")` returns `url`. `landsOnSource` is `true`, `result.converted` is `false`, and [`Writer.replaceInPlace`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/Writer.swift#L13) replaces `foo.pdf` with the rewritten PDF.
* **Trace (PDF to AVIF preset):** If a PDF reaches `Preset.avif` (`format: .avif`), [`core/src/lib.rs:835`](file:///Users/bemeadows/Projects/.lanes/squint-sign/core/src/lib.rs#L835) checks `format != OutputFormat::Jpeg` and returns `Error::ReadOnlyFormat`. Swift catches the error and marks the job `.failed`; no file is written.
* **Trace (Picture to PDF):** Image optimization in `core/src/lib.rs` never generates `%PDF` magic bytes, so `outputExtension` never evaluates to `"pdf"`.

#### 2. Analysis of `landsOnSource`
* **Confirmed by reading:** [`JobQueue.swift:150`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/JobQueue.swift#L150) compares `destination.path.lowercased() == url.path.lowercased()`.
* **Case-sensitive APFS volume fault:**
  * **Input:** A file named `Photo.AVIF` on a case-sensitive filesystem passed to `Preset.avif`.
  * **Behavior:** `destination` becomes `/path/Photo.avif` (lowercase extension). `url` is `/path/Photo.AVIF`. Lowercasing both paths evaluates `/path/photo.avif == /path/photo.avif` as `true`.
  * **Cost:** **Wrong refusal.** [`JobQueue.swift:153`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/JobQueue.swift#L153) triggers the `result.converted && landsOnSource` guard and fails with `"this picture is already an AVIF, so converting it would only overwrite it"`, even though `Photo.AVIF` and `Photo.avif` are two distinct files on a case-sensitive volume.
* **Normalization / Symlinks / Trailing Slashes:**
  * `destination` is derived via `url.deletingPathExtension().deletingLastPathComponent().appendingPathComponent(...)`, maintaining `url`'s exact string normalization and path component format.
  * If `url` is a symlink (e.g. `link.jpg` -> `target.jpg`) and processed in-place, `replaceItemAt` in `Writer.replaceInPlace` replaces the symlink path itself with a regular file.

#### 3. `converted` Flag & In-Place Write Guard
* **Confirmed by reading:**
  * **`converted` set, in-place write attempted:** In [`JobQueue.swift:153`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/JobQueue.swift#L153), if `result.converted` is `true` and `landsOnSource` is `true`, the job immediately fails and returns. No converted output can ever reach `Writer.replaceInPlace`.
  * **`converted` NOT set, destination is a different file:** Yes. For presets with `suffix != nil` (e.g., `Preset.email` with `suffix = "-email"`), a JPEG input (`photo.jpg`) produces `converted_from = None` in Rust ([`core/src/lib.rs:897`](file:///Users/bemeadows/Projects/.lanes/squint-sign/core/src/lib.rs#L897)), mapping to `converted = 0` in [`core/src/ffi.rs:202`](file:///Users/bemeadows/Projects/.lanes/squint-sign/core/src/ffi.rs#L202). `destination` is `photo-email.jpg` (`landsOnSource` is `false`). It writes beside the original. `converted` is `false`, but the write goes to a derived file as intended by the suffix rule.

#### 4. `outputExtension` Magic Inspection
* **Confirmed by reading:**
  * In [`JobQueue.swift:145`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/JobQueue.swift#L145), `result.outputExtension` reads from `result.data` (the output bytes generated by Rust `squint_optimize_as`), never from the input bytes.
  * In [`Engine.swift:86`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/Engine.swift#L86), `data[4..<8].elementsEqual("ftyp".utf8)` checks offset 4 of output `data`. JPEGs start with `0xFF 0xD8 0xFF` and PNGs start with `0x89 0x50 0x4E 0x47`. Neither can ever contain `ftyp` at offset 4. Only ISOBMFF outputs (AVIF) hit this branch.

#### 5. Name Collisions
* **Trade-off Analysis:**
  * **Current behavior (Silent overwrite):** Converting both `photo.jpg` and `photo.png` in the same directory yields `photo.avif`. Processing `photo.png` second silently overwrites the `photo.avif` produced from `photo.jpg`.
  * **Alternative (Disambiguated naming, e.g. `photo-jpg.avif` or `photo.png.avif`):** Prevents accidental loss of derived output files from co-located stem collisions, but breaks deterministic output path expectations where re-running conversion on `photo.jpg` predictably replaces `photo.avif`.

#### 7. Concurrency & Memory
* **Confirmed by reading:** There is no path where a quality-mode memory load runs at core-count concurrency.
* `JobQueue.concurrencyLimit` ([`JobQueue.swift:46`](file:///Users/bemeadows/Projects/.lanes/squint-sign/app/Sources/JobQueue.swift#L46)) checks `jobs.contains(where: { $0.mode == .quality })`.
* `Preset.avif` and `Preset.plain(.quality)` both use `.quality` mode, throttling concurrency to physical memory limits.
* `Preset.plain(.fast)` uses `.fast` mode. When a PDF is processed under `.fast` mode, concurrency is bounded by CPU cores, but Rust `pdf::rewrite` runs single-pass encoding without perceptual SSIMULACRA2 search, keeping per-job memory usage low.
